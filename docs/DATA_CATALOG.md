### dim_protocol

A protocol is one DefiLlama id, so a rename, which changes the slug and keeps the id, gives one row under the newest slug. - **Grain:** protocol_id

| `protocol_name` | VARCHAR | text | Protocol name. |
| `category` | VARCHAR | text | DefiLlama category. |

### fct_supply_daily

Supply and implied issuance per UTC day. Epochs end at uneven times, so one day's minted_near is lumpy; use averages of 30 days or more.

- **Grain:** date_day
- **Sources:** NearBlocks /v1/charts, archival RPC, protocol config
- **File:** `data/gold/fct_supply_daily.parquet`

| Column | Type | Unit | Description |
|---|---|---|---|
| `date_day` | DATE | date | UTC calendar day. |
| `total_supply_near` | DOUBLE | NEAR | Total supply at day end per NearBlocks. |
| `circulating_supply_near` | DOUBLE | NEAR | Circulating supply per /v1/charts. The v3 stats endpoint reports this wrongly, so it is not used. Stale: the value has read 1,249,836,992 on every day since 2025-08-27, so treat it as unknown from then on. |
| `onchain_supply_end_of_day_near` | DOUBLE | NEAR | Supply in the first block of the next day, read from the archival node. Empty where no daily block exists. |
| `protocol_version` | INTEGER | integer | latest_protocol_version in the block header: the version the block's producer supports, which can lead the version in force by days (87 appeared on 2026-11-04; the config switched between the 11-04 and 11-05 reads). Date a change from fct_protocol_config. |
| `gas_fee_near` | DOUBLE | NEAR | Gas fees per /v1/charts. |
| `supply_change_near` | DOUBLE | NEAR | Change in total supply from the previous day. |
| `contract_gas_reward_rate` | DOUBLE | fraction | Share of gas paid to the called contract on that day (the developer gas rebate): the newest protocol config read on or before the day, and the first read's 0.3 before 2026-10-28. It became 0 with protocol version 87, first read on 2026-11-05. |
| `burn_near` | DOUBLE | NEAR | Gas fees minus the contract share in force that day. Before protocol version 87 that is 70% of gas; from 2026-11-05 all of it. |
| `treasury_reward_near` | DOUBLE | NEAR | EpochRewards received by treasury.near that day, from wallet transfers. Part of minted_near, not on top of it. |
| `minted_near` | DOUBLE | NEAR | supply_change_near plus burn_near: issuance implied by the chain. |
| `minted_annualized_rate` | DOUBLE | fraction per year | minted_near times 365, divided by total supply. Noisy for a single day. |
